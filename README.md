# SLA Dashboard

## Налаштування робочого графіка

Графік задається параметрами `WORK_START`, `WORK_END`, `LUNCH_START` і
`LUNCH_END`. Їх можна додати до Streamlit Secrets або змінних середовища;
значення зі змінних середовища мають пріоритет.

Час приймається у форматі повної години (`11`) або години та хвилин
(`11:00`). Якщо параметри не задані, застосовується графік 11:00–19:00 з
обідом 14:00–15:00.
